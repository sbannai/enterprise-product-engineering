Client Tickets & Feedback

Product Admin reviews client-submitted tickets and feedback across authorized customer/application scopes. Client users see and manage only tickets for their own selected application.

Central support queue

Filter by customer/tenant, application, type, severity, status, owner and date. Review defects, feedback, feature requests and questions as separate categories.

TicketCustomerApplicationTypeSeverityStatusOwner
No live queue loaded — authenticated support API connection required.

Duplicate reports link to a canonical ticket. Only confirmed, evidence-backed defects count toward P1 tracking.

Access rules

  • Product Admin: cross-client queue only with explicit platform support permission; all access is audited.
  • Client: create, view and follow up only on tickets tied to their own tenant and selected assigned application.
  • Cross-tenant records must not be disclosed through search, filters, errors or exports.
  • Security/privacy reports use restricted visibility and immediate escalation.
This is a static wireframe. Queue filters, assignment, comments, status updates and exports are not connected here.
